# ctf-notes

Writeups for CTF challenges I solve.

> **Current state: writeup workflow and template.** This repository contains the structure for documenting authorized, reproducible challenge solutions. It does not claim that a challenge has been solved unless a corresponding writeup is present.

## Categories

- Web
- Crypto
- Pwn
- Forensics
- Reversing
- Misc

## Writeup template

Start new entries from [templates/writeup.md](templates/writeup.md). It records challenge scope, publication permission, tool versions, reproducibility details, solve steps, failed approaches, root cause, and lessons learned.

## Publication rules

No flags of active HTB machines are published. Respect event rules and release status. Remove real credentials, session cookies, VPN details, private hostnames, personal filesystem paths, and unrelated logs. Use synthetic fixtures rather than production data. Screenshots and terminal recordings need the same redaction review as text.
